lyra-overlays
=============

This is a simple tool to configure, build, and install device tree
overlays on Luckfox Lyra boards. It is effectively a replacement for
the vendor's `luckfox-config` tool, but it works exclusively with
overlay files.

This project is part of [Debian on Luckfox Lyra][].

 [Debian on Luckfox Lyra]: https://github.com/agrif/debian-lyra
